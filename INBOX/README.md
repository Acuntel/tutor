# INBOX

Drop anything here, unsorted and unedited. A prompt PDF, a screenshot of a Brightspace
announcement, an email, notes typed in a hurry, a photo of the whiteboard, a graded paper.

Then say "file the inbox". Everything gets read in full, the verbatim original gets saved
into the right course folder, the distilled files get updated, anything ambiguous goes to
`../OPEN-QUESTIONS.md`, and the file gets cleared out of here.

Do not organize before dropping. That is the point.
