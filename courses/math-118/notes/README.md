# MATH-118 class notes

One file per meeting, named `YYYY-MM-DD.md`. Meets Lecture Mon/Wed/Fri, discussion Thu.

Capture: anything said out loud about assignments or exams, dates announced in class,
policy changes, and what the instructor emphasizes.

## Dictated lectures

Lectures captured with NessoTalk PTT land here as two files:

- `YYYY-MM-DD-lecture-transcript.md`, the raw speech-to-text, never edited
- `YYYY-MM-DD.md`, the distilled version: formulas in clean notation, worked examples,
  and a list of anything the transcriber garbled

**The dictation app does not save transcript text.** `~/.dictation/ptt.log` records only a
word count and a hash, for example `✓ 526 words · 5337fb`. The text lives in the clipboard
until something overwrites it. So a dictated lecture has to be pasted or filed the same day,
or it is gone. The word count in the log is what confirms a recovered clipboard is the right
session.
