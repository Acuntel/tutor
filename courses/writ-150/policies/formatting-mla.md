# WRIT 150 formatting checklist

Source: `../syllabus/2026-fall-writ150-syllabus-verbatim.md`, section "Writing Projects".
The syllabus says these exist "to avoid deductions", so each one is free points.

Run this checklist on every final draft before submitting.

- [ ] Times New Roman, 12 point, throughout. No bold, no italic, no script anywhere.
- [ ] Double spaced.
- [ ] 1 inch margins on all four sides.
- [ ] **No extra blank space between paragraphs.** Word and Google Docs add this by default.
      Set paragraph spacing before and after to 0.
- [ ] An original title, in the same font and size as the body. Not bold, not larger, not
      underlined, not centered in a different style.
- [ ] First page header, upper left corner, four lines:
      ```
      Brady Schwartz
      Alison Minami
      Writ 150
      [date]
      ```
- [ ] Running header, upper right corner, **on every page**: `Schwartz [page number]`.
- [ ] MLA style for citations and works cited.

Reference the instructor recommends: the Purdue OWL MLA guide, specifically their Sample Paper.

## Google Docs gotchas

- Default font is Arial 11. Change it, including in the header.
- Default line spacing is 1.15. Change it to Double.
- Format, then Line and paragraph spacing, then Custom spacing, then set Paragraph spacing
  Before and After to 0.
- Insert, then Headers and footers, then Header. Insert, then Page numbers, top right.
  Then type `Schwartz ` before the page number field.
- The header font resets to default. Set it to Times New Roman 12 inside the header too.

## Submission mechanics

- Everything is submitted on Brightspace.
- AWAs are written in the Google workbook first, then copied into Brightspace as a Word
  file, a PDF, or into the text box.
- Rough drafts for peer review must be typed and count as AWAs.
