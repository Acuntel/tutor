# Field notes

One file per shift, named `YYYY-MM-DD.md`.

Write these the same day, in your own words, before the details fade. Suggested shape:

- What happened, concretely. Who was there, what was said, what was done.
- A specific moment worth remembering. A quote, an exchange, an image.
- What surprised me or contradicted what I expected.
- A question it raised.
- Something about my own position in the room.

These are the evidence base for the Writing Projects. Specificity now is what makes an
argument concrete in December.
