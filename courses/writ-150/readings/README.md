# Readings

Readings come from the WRIT 150 Course Book on Kortext and from Brightspace.

Structure:
- Keep the source PDF or a link in this folder.
- One notes file per reading, named `author-shorttitle.md`.

Notes template:

```markdown
# [Author], "[Title]"

**Source:** Course Book / Brightspace | **Assigned for:** YYYY-MM-DD | **Feeds:** WPx

## Full MLA citation
[citation]  — verified: yes/no

## Argument in one sentence
[in my own words]

## Key passages
> "[quote]" (page)
Why it matters:

## What I disagree with or question

## How this connects to my service-learning
```

Quotes must be transcribed exactly, with page numbers, at the time of reading. That is what
makes citation trivial later and prevents a misquote in a paper.
