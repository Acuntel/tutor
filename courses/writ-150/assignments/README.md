# Assignments

One file per graded item. Each file tracks the item from prompt to returned grade so that
nothing about the requirements is ever reconstructed from memory.

Template for a new assignment file:

```markdown
# WPx: [title]

**Due:** YYYY-MM-DD (weekday) | **Weight:** x% | **Status:** not started

## Prompt (verbatim)
Paste the instructor's exact prompt text here. Never paraphrase it in this section.

## Requirements checklist
- [ ] length
- [ ] number and kind of sources
- [ ] required elements
- [ ] formatting (see ../policies/formatting-mla.md)

## Related AWAs
Ancillary work that feeds this WP, and its due dates. All of it must be done BEFORE the
essay is written, or it earns nothing.

## Peer review
Date, what was due, what feedback was received.

## Conference
Date, what was discussed, what she asked for.

## My working thesis
In my own words.

## Sources
Author, title, publication, date, where found, and the MLA citation. Verified: yes or no.

## Returned grade and comments
Her comments verbatim. Whether a rewrite is worth using here.
```
